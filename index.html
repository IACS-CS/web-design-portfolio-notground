CSS Zen Garden Project

The Zen Garden Project is meant to challenge a students ability to use only CSS to change a web page. My first design features a pink theme featuring drawings of my cat, Glen coco. I change the layout so that the main text is in the middle of the screen, the sidebar is on the left, and on the right is a full drawing of my cat (on compatable screens). For my second design, which was optional, I coppied the same page layout but made everything a differet color to make a rainbow theme.
